## 식재료 화면
 - 현재 음식 데이터가 존재하지 않으면, 화면 중간에 네모 모양의 점선으로 + , 한줄 띄우고 , 식재료 추가하기 버튼 추가하기
 - 식재료 추가하기 버튼을 누르면 직접 입력하기, 영수증 촬영하기 두 버튼이 뜨도록 설정
 - 직접 입력하기를 누르면 식재료 이름, 카테고리 선택, 구매일 선택, 유통기한 선택, 메모 입력 (선택) 을 입력할 수 있는 입력창이 뜨고,
밑에는 저장 버튼 추가하기
 - 카테고리는 누르면 육류, 채소, 유제품, 냉동식품, 소스/양념, 기타 중에서 선택할 수 있도록 설정 ( 모든 카테고리에 어울리는 사진 추가하기 )
 - 구매일과 유통기한은 누르면 달력이 뜨고, 구매일은 오늘이 기준, 유통기한은 AI기반으로 일반적으로 얄려져있는 유통기한 범위를 자동으로 설정
 - 영수증 촬영 버튼을 누르면 카메라가 뜨고 영수증을 틀에 맞게 촬영할 수 있또록 네모 외곽선이 모서리 부분에 뜨도록 설정 ( 이 부분은 임의로 카메라 화면, 영수증 화면 추가하기 )
 - 촬영을 하면, 영수증 화면을 인식 결과가 뜨도록 설정 (식재료 이름, 몇g, 몇 개 등등..)

 # 추가 사항 

## 로그인 화면
 - 로그인,회원가입,비밀번호 찾기 기능 추가 
 - 로그인 실패시 아이디 또는 비밀번호가 틀렸습니다 텍스트 띄우기
 - 로그인 성공시 홈 화면으로 이동

 - 아이디는 중복확인이 가능하도록 설정 (임의로 설정한 아이디와 중복인지 확인하는 화면을 띄워주기)
 - 닉네임은 중복확인이 가능하도록 설정 (임의로 설정한 닉네임과 중복인지 확인하는 화면을 띄워주기)
 
## 식재료 화면
 - 식재료 화면 상단에 유통기한 임박, 냉장, 냉동, 실온, 기타, 찜 목록 버튼 추가
 - 유통기한 임박 버튼을 누르면 유통기한이 3일 남은 식재료만 뜨도록 설정
 - 냉장 버튼을 누르면 냉장 보관인 식재료만 뜨도록 설정
 - 냉동 버튼을 누르면 냉동 보관인 식재료만 뜨도록 설정
 - 실온 버튼을 누르면 실온 보관인 식재료만 뜨도록 설정
 - 기타 버튼을 누르면 기타 보관인 식재료만 뜨도록 설정
 - 찜 목록 버튼을 누르면 찜 목록에 있는 식재료만 뜨도록 설정

# 수정 사항 

## 홈 화면
 - 유통기한이 3일 이내인 식재료가 존재하면, 홈 화면의 유통기한 임박 식재료 탭에 띄우기
 - 유통기한이 3일 이내인 식재료가 없으면, 홈 화면의 유통기한 임박 식재료 탭에 '유통기한 임박 식재료가 없습니다.' 문구 띄우기


## 추가사항 

 - 식재료 목록을 누르면 해당 식재료의 상세 정보가 뜨도록 설정 (카테고리, 구매일, 유통기한, 보관위치, 메모, 사진)
 - 식재료 상세 정보 화면에서 수정, 삭제 버튼 추가 (수정 버튼은 #ecf2f0, 글자 색깔은 #379271, 삭제 버튼은 #cc0000, 글자 색깔은 #FFFFFF)
 - 식재료 리스트에 간단한 바형태로 남은 유통기한을 색깔로 표현하기 (6칸, 6칸 모두 채워졌다면 빨강, 하나 줄었다면 주황, 3칸 이하면 노랑, 1칸 이하면 초록 등등)
 - 식재료 리스트에 존재하는 식재료에 알맞는 간단한 아이콘 표시하기 (돼지고기 삼겹살이면 돼지고기 삼겹살 사진, 계란이면 계란 사진 등등)
 - 식재료 리스트에서 유통기한이 지난 식재료는 빨간색으로 표시하기
 - 

## 가계부 화면
 - 가계부와 관련된 카테고리, 화면 모두 삭제하기 

## 장보기 화면
 - 상단에 내 장보기 목록, 구성원 장보기 요청 목록 탭 추가하기
 - 내 장보기 목록에 + 버튼을 누르면 식재료 추가하기 화면이 뜨도록 설정 (식재료 화면의 직접 입력하기 화면과 동일) ( 단, 구매일, 유통기한 설정 불필요, 보관장소 설정 불필요)
 - 내 장보기 목록에 뜨는 식재료는 구매일, 유통기한이 표시되지 않도록 설정 
 - 내 장보기 목록에 뜨는 식재료에 체크를 할 수 있도록 체크박스 추가
 - 전체 선택 버튼 추가
 - 구성원 장보기 요청 목록에는 구성원이 요청한 식재료와 요구량이 뜨도록 설정 
 - 구성원 장보기 요청 목록에 구성원이 요청한 식재료가 뜨면, 내 장보기 목록에 추가할 수 있도록 설정
 - 구성원 장보기 요청 목록 상단에 '(닉네임)님이 재료를 사오라고 요청했어요!' 라는 문구와 요구량 표시
 - 장보기 목록에서 구성원 장보기 요청 목록의 식재료 옆에는 누구가 요청했는지 프로필 사진과 함께 표시
 - 요청 문구 아래에 요청한 날짜 표시 (YYYY.MM.DD(요일) 오전/오후 12:30)

# 수정 사항

## 회원가입 화면
 - 중복확인 버튼을 입력창과의 높이가 일치하도록 설정
 - 중복확인 버튼을 눌렀을 때, 중복확인 결과가 뜨도록 설정 (이미 사용 중인 아이디 입니다. / 사용 가능한 아이디 입니다.)
 - 닉네임 중복확인 버튼을 눌렀을 때, 중복확인 결과가 뜨도록 설정 (이미 사용 중인 닉네임 입니다. / 사용 가능한 닉네임 입니다.)
 - 비밀번호 확인 입력창에 비밀번호를 입력하고, 비밀번호 입력창과 비밀번호 확인 입력창의 값이 일치하면 비밀번호 확인 입력창 아래에 작은 초록색 글씨로 ( 비밀번호가 일치합니다. ) 라는 문구 띄우도록 설정
 - 비밀번호 확인 입력창에 비밀번호를 입력하고, 비밀번호 입력창과 비밀번호 확인 입력창의 값이 일치하지 않으면 비밀번호 확인 입력창 아래에 작은 빨간색 글씨로 ( 비밀번호가 일치하지 않습니다. ) 라는 문구 띄우도록 설정
 - 회원가입을 완료하면, 가구 생성하기, 가구 참가하기 버튼을 작은 화면에 띄워주기 
 - 가구 생성하기를 누르면 가구 생성 화면이 뜨도록 설정 (가구 코드가 랜덤으로 생성되도록 설정, 생성된 가구 코드 표시)
 - 가구 참가하기를 누르면 가구 참가 화면이 뜨도록 설정 (가구 생성 화면에서 생성된 6자리 가구 코드를 입력하여 가구에 참가)
 - 회원가입 후 소스나 장 종류를 선택하면, 선택한 소스는 자동으로 식재료 정보에 추가되도록 설정

 - 설정 메뉴 안에는 프로필 설정, 구성원 설정, 로그아웃, 회원탈퇴 설정, 버전 정보 표시

 # 수정 사항

 ## 전체 수정
 - 유통기한이 얼마 남지 않은 식재료가 메인화면에 뜨는 개수 늘리기 
 - 처음 회원가입 했을 때, 어떤 데이터도 남아있지 않도록 설정 (식재료, 구성원 요청 목록)
 

## 식재료 화면
 - 식재료 추가 할 때, 유통기한이 통상적으로 알려져있는 식재료들의 유통기한이 적용되도록 설정 (예: 우유 3일, 계란 7일, 생선 2일, 고기 3일 등, 캔,통조림 종류는 제조일로부터 2년 후 등으로 설정, 라면같은 경우는 1년 후 등으로 설정, 소스는 6개월 등 유통기한이 대체적으로 알려져있는 식재료들의 유통기한 적용)
 - 식재료와 요리에 표시되는 사진이 기본으로 설정되어 있는 것이 아니라, 식재료와 요리에 맞는 사진이 뜨도록 설정 (AI로 사진을 만들어서 적용)

## 요리 화면

 - 레시피에 들어가는 이해하기 쉬운 레시피 그림은 AI로 사진을 만들어서 적용
 - 요리의 메인 사진은 만개의 레시피에서 제공하는 음식 사진으로 대체

======== 12번 째 수정 사항 =========

# 수정 사항

## 전체 수정
 - 식재료 이름을 작성할 때, 두 개 이상의 식재료를 한 번에 입력하기 (예: 소고기, 우유, 달걀, 물) 쉼표를 추가하면 전에 적은 식재료는 하나의 그룹으로 만들기 (초록색 네모)
 - 식재료 직접 입력을 완료하면, 마지막에 팝업창으로 확인 화면이 뜨고 거기서 수량과 유통기한을 확인 후 냉장고에 추가
 - 장보기 식재료 추가 할 때도 동일하게 적용
 - 팝업창에 표시되는 이미지도 식재료에 맞는 이미지로 표시

## 요리 화면
 - 요리 레시피의 부족한 식재료가 이상하게 뜨는 버그 수정 (재료의 이름, 수량이 따로 뜨는 버그) -> "스트로베리 50g" , "양상추 100g" 이런식으로 뜨도록 수정
 - 요리 레시피의 부족한 식재료를 구매할 떄, 바로 장바구니에 추가하지 않고 주황색 네모로 변경된 다음 하단에 있는 구매 버튼을 눌러야 장바구니에 추가되도록 설정
